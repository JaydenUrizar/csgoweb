# utility — Haze / Strobe / Pulse (src/combat/utility/**)
Files: `index.js` (API, throw, inventory, loops) · `sim.js` (grenade physics) · `world.js` (BVH wrapper) · `haze.js`+`hazeShader.js`+`noise.js` (smoke) · `strobe.js` · `pulse.js` · `fx.js` (flares/rings/sparks) · `screenfx.js` (blind overlay) · `models.js` · `lab.js` (`?scene=utility-lab`). All constants: `config.js`.

## API (`ctx.combat.utility`)
`throw(actor,type,power='strong'|'weak'|'medium'|0..1, {instant,delay})` -> bool (consumes from `actor.inventory.utility`, fires `util:throw` + `viewmodel.event('throw',{type,power,delay})`, releases after 0.16 s arm swing; direction/velocity sampled at release) · `count(actor,type)` · `grant(actor,type,n)` (limits haze1/strobe2/pulse1, 3 total; `give/select` are no-op notifications from the tagger inventory) · `trajectory(actor,type,power,out?)` -> Vector3[] (same integrator, reuses `out`) · `preview.show(actor,type,power)/hide()` dashed arc + landing ring · `blocksLine(a,b)` (>=0.85 m of smoke) · `opticalDepth(a,b)` (metres of full density) · `inSmoke(p)` · `smokes` (live cloud list: `pos, seed, radius, extent, age, density(x,y,z)`) · `punch(origin,dir,len)` / `disturb(pos,r)` · `blindAmount(actor)` 0..1, `isBlind` · `infinite` (practice) · `setWorld(mesh|null)` · `clear()` · `debug.{spawn(type,pos[,vel]), throwFrom(x,y,z,yaw,pitch,type,power,vel), detonateAll, state(), launch(actor,power)}`.
Events emitted: `util:throw`, `util:bounce {type,pos,speed}`, `util:detonate {type,pos,thrower}`, `util:blind {actor,amount,duration,hold,thrower,dist}`, `util:pulse:hit`, plus `tag:hit/tag:out` via `ctx.combat.applyTag` (fallback: direct hp/armor). Listens: `weapon:fire` (bullets carve smoke wakes), `round:start` (clear). Sounds are NOT called directly: the audio module binds those events.
Actor fields written: `actor.blind={amount,t0,dur,hold,until}` (bots: use `blindAmount`), `actor.stagger={until,amount}` + velocity impulse (pulse).

## Mechanics (CS2-derived)
Throw: speed 16.5*(0.3+0.7s) m/s (s=1 left, .5 both, 0 right), 10 deg lift tapering to 0 at poles, release 0.3 m ahead and (1-s)*0.23 m lower, inherits 1.25x thrower velocity (0.85x crouched; jump-throws inherit vertical), crouch = lower release point. Physics 120 Hz, sphere r=0.07, sub-steps <= 0.8 r + closest-point depenetration against the map BVH (no tunnelling, edges/stairs/slopes natural), restitution .45 / tangent keep .8 (per surface via `map.surfaceAt`), rolling friction, rest detection, bounce off actors, deterministic. Fuses: Haze pops at rest (max 3 s), Strobe 1.55 s, Pulse 1.6 s; emissive band blinks faster toward the pop.
**Haze**: incremental voxel flood-fill (0.5 m cells, 1100-cell budget ~ 137 m^3, Dijkstra by distance from a seed 1.2 m above the grenade, each step BVH-ray tested so walls/floors/ceilings stop it and corridors fill ~8 m each way), ~1.2 s expansion, lasts 18 s (shell dissolves from 12 s). Density field drives `blocksLine`; render = <=600 sorted sphere-impostor puffs (Beer-law soft edges, noise erosion, sun-lit lobes, self-shadow, forward scatter, gl_FragDepth so they intersect geometry), camera-inside murk overlay, bullet wakes (tunnels refill in ~1.9 s), Pulse/Strobe disperse/light it.
**Strobe**: amount = facing(0.15..1) x distance(full <=3.5 m, 0 at 36 m) x LOS(3 eye samples) x exp(-smoke); duration 0.5-4 s, full white for `hold`, quadratic fade, frozen blurred afterimage (needs render canvas readback; own DOM overlay above canvas/below HUD). **Pulse**: radius 7 m, 60 max (x falloff^1.25, x0.4-1 cover, armor absorbs 50%, self x0.6, teammates 0), knock 6.2 m/s + 2 up, camera shake, hex energy dome + ground ring + sparks.

## Known gaps / ideas
Smoke is stylised (lobed, soft) rather than CS2's wispy dust; no scene-depth soft particles (cut lines where puffs meet walls); walker wakes not implemented; no refraction in the Pulse dome; afterimage only when canvas readback works; trajectory ignores actor bodies; Pulse not blocked by smoke.
