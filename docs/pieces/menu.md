## Inspect
* `?test=1` → menu fully inert (no backdrop built, render untouched). `?test=1&menu=1` shows main menu; add `&boot=1` for the loading screen. Normal URL = boot → menu.
* `?test=1&menu=1&scene=menu-gallery` cycles all screens (`&every=ms`), `&screen=<id>` shows one: boot, main, settings:{controls,video,audio,crosshair,viewmodel}, help, credits, pause, end:win, end:loss, tutorial:0-3, cheat.
* `node tools/menu_sheet.mjs [--sizes 1280x720,1920x1080] [--only main,pause]` → `shots/menu/*.png` + `sheet_<w>.png`.
* Console: `ctx.menu.debug.{show(id),play(),openPause(),resume(),showEnd('ember'|'tide'),tutorial,settings,backdrop}`.
## Behaviour
Play/Practice → `ctx.match.startMatch({difficulty:'rookie|pro|elite',playerTeam,bots,practice,mode,map,name})` (Practice prefers `debugScenes.range`). Esc/pointer-unlock in game → pause (engine.paused + match.pause); Resume re-locks. `match:end` → recap after 2.6 s (MVP, tables, history, Play again/Main menu). Leave → `match.quit()`. Locker → `cosmetics.openLocker({side})` (menu hides until `locker:close`). F1 = controls cheat-sheet anywhere; first-run tutorial (N skips step). Emits `ui:hover/click/tick/open/close`, `ui:test{bus}`, `menu:state`, `menu:play`, `game:pause`. HUD/other #ui children are hidden while the menu world is up (`html.fx-menu`).
## Settings keys written (ctx.settings)
sensitivity (CS units), mouseDpi, invertY, fov (horizontal), autoBhop, crouchToggle, headBob, keybinds {action:[code,code]} (applied via `input.rebind`, old codes unbound with `rebind(code,null)`), quality, showFps (menu draws counter), screenShake (render reads it), colorblind (off|deut|prot|trit), volume/sfxVolume/musicVolume/voiceVolume, hudScale, crosshair{style classic|t|dot|circle,size,gap,thickness,color,dot,outline,dynamic}, viewmodel{fov,offsetX/Y/Z,bob}, playerName, menuPrefs, tutorialDone.
