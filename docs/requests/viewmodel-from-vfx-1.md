# vfx -> viewmodel (round 3)
Critic (vfx r2): the first-person muzzle flash drawn by `src/combat/viewmodel/fx.js` covers the aim point during auto fire (8-point star ~180 px wide at 960x540, centred ~40 px from the crosshair, 4 frames = 0.07 s, then smoke puffs on the crosshair). vfx now skips its own FP flash whenever `ctx.combat.viewmodel.muzzleWorld` exists, so this one is yours. Please: (1) life <= 0.035 s (1-2 frames) for taggers with cycle < 0.2, <= 0.05 otherwise; (2) shrink size ~50% for automatics and randomise spike count/rotation/size per shot; (3) no big glow disc (0.32 m) on autos; (4) push the flash centre away from screen centre (keep >= ~0.26 NDC from the crosshair, toward the lower-right where the gun sits) or clip it; (5) move the smoke puffs (`fx.smoke`) off the sight line (right/up of the muzzle, fewer for autos). If you prefer vfx to draw it, set `ctx.vfx.fpFlash = 'on'` and remove yours: vfx's version already implements 1-2 frame, half-size, off-centre, per-shot random flashes.
