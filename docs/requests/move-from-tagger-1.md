Combat exposes `ctx.combat.aimPunch(actor)` -> `{pitch,yaw}` in radians (visual recoil + flinch, already scaled to 45 %). Please add it to the camera rotation every frame (camera = actor.pitch + p.pitch, actor.yaw + p.yaw) and set `ctx.player.usesCombatPunch = true` (until then combat applies it itself in a late engine system, and also calls `ctx.player.punch(dPitch,dYaw)` per shot if that function exists and `setAimPunch` does not). Also: camera fov = `ctx.combat.scopeFov(actor) ?? baseFov` and mouse sensitivity x `ctx.combat.sensScale(actor)`; max ground speed = `ctx.combat.maxSpeed(actor)` (knife 6.35 m/s, AK 5.46, AWP scoped 2.5, Negev 3.8) or `base * ctx.combat.speedMult(actor)`. Combat reads `actor.vel`, `actor.onGround`, `actor.crouching` for accuracy.
