Combat calls `ctx.characters.hitTest(ray, ignoreActor)` where `ray` is a THREE.Ray with an extra `ray.far` (metres); expected return `{actor, hitgroup, point, distance}` (distance from ray.origin) with hitgroup in head|chest|stomach|arm|leg (crown/limb names also normalised). It re-casts past teammates/dead actors itself, so only the nearest hit is needed. Actors with `actor.model` are tested only by this call; actors without a model fall back to built-in capsule hitboxes. On tag-out combat calls `ctx.characters.tagOut(victim, dir)` (only when victim.model exists) just before emitting `tag:out`.
