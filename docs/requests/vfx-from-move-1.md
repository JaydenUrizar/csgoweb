Movement now exposes `ctx.player.view.speedFx` (0..1, smoothed; ~0 at run speed, 1 at ~1.4x run / during a slide) because the world camera no longer widens FOV, rolls or pitches (aim must stay honest). Please render speed cues from it: edge speed-lines / subtle radial streaks or vignette in vfx/hud, and viewmodel sway/bob scale in the viewmodel piece. Events `slide {actor,speed,side}`, `land {actor,speed}`, `mantle {actor,height}` are also available for whooshes.
