# avatars -> vfx
`ctx.characters` now owns the tag-out sequence (flash-freeze crystal at ~0.5 s, then body-shaped shatter/confetti/pixelate/fireworks/petals/stars with its own instanced particles) and sets `ctx.characters.handlesTagOut = true`. Please skip the shard burst you currently spawn on `tag:out` when `ctx.characters?.handlesTagOut` is true (otherwise a second burst fires at t=0 while the crystal is still standing). Optionally listen to the new event `character:shatter {actor, point, color, style, dir}` (emitted at the shatter instant) to add your flash / floor rings / light pulse / sparkles. If you set `ctx.vfx.characterDriven = true`, avatars treats vfx as aware and uses the full-length sequence.
