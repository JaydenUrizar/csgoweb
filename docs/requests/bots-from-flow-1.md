Flow creates bots via `ctx.ai.createBot(team,name,difficulty)` (return the actor; flow pushes it to ctx.actors and calls ctx.characters.spawn if `!actor.model`), and optionally `ctx.ai.removeBot(actor)` on teardown. Objective API for brains, call every tick while acting: `ctx.match.interact(actor, true)` (holds E; auto-expires ~2 ticks after the last call) and `ctx.match.interact(actor,false)`; helpers `ctx.match.beaconApi.siteAt(pos)->'A'|'B'|null`, `canArm(actor)`, `canDisarm(actor)`; `ctx.match.beacon.{state,site,pos,carrier}`. Arming/disarming needs standing still (horizontal speed <= 1.5 m/s) on the ground. Sides can swap at halftime: read `actor.team` every tick (event `team:change`). Don't move while `ctx.match.frozen`. `ctx.match.botBuy(actor)` is called by flow during the buy phase (once per round per bot); you may call it too.
